# Bug Reports

This folder contains bug reports identified during manual testing of the OrangeHRM demo application.

The reported issues cover different areas of the system, including:
- input validation
- authentication and password management
- search functionality
- user interaction and edge cases

Each bug report includes:
- preconditions
- environment details
- steps to reproduce
- expected and actual results
- severity and priority
- additional notes and observations

These reports demonstrate practical bug identification and documentation skills.
